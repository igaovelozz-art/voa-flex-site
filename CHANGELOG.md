# Changelog

Todas as mudanças relevantes deste projeto são registradas aqui.

O formato segue [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e o versionamento segue princípios de [Semantic Versioning](https://semver.org/lang/pt-BR/).

## [Não publicado]

## [2.1.0] - 2026-09-09

### Adicionado

- Blueprint completo para deploy como Render Static Site.
- Pipeline de build isolado em `render-dist/` com endpoint `/health.json`.
- Validação automática de Node, rotas, headers de segurança, CSP e arquivos de saída.
- Documentação de criação, domínio, verificação e rollback no Render.

### Alterado

- Node.js fixado em 24.14.1 com limite de versão principal.
- GitHub Actions passou a validar o pacote exato utilizado pelo Render.
- JavaScript da página de obrigado foi externalizado para permitir uma CSP mais restritiva.
- Cache de assets ajustado para arquivos ainda não versionados por hash.

## [2.0.0] - 2026-09-08

### Alterado

- Posicionamento completo para uma logtech premium, seletiva e orientada à aderência operacional.
- Hero, arquitetura da home, linguagem dos CTAs, formulários e chatbot.
- Preços reposicionados como parte de uma análise sustentável, sem promessa de menor tarifa.

### Adicionado

- Padrão VOA, análise de aderência e solicitação de entrada.
- Identidade Seller VOA, badge Seller Partner e jornada de relacionamento.
- Sellers Fundadores, VOA Select e VOA Circle com limites de promessa explícitos.
- Status real de cobertura, seção de capacidade controlada e regras operacionais consolidadas.
- Camada visual premium, microinterações e novos tratamentos responsivos.

## [1.5.0] - 2026-09-08
